# lingua_design_system

Flutter implementation of the canonical specification in the repository-root
`design-system/` directory. Import the public barrel:

```dart
import 'package:lingua_design_system/lingua_design_system.dart';
```

The package contains generated tokens, adaptive layout, primitives, components,
patterns and their golden tests. It must not depend on application features,
auth, networking or platform-specific foldable plugins.
